# cribbage-simul8or
run the various communication phases of an online cribbage game, occupying authentication to choosing a dealer, right down to scoring (YES)

### tech
- vfaas kv functions, applied with db and (augmented) vm functions

- [x] assign dealer
- [x] shuffle
